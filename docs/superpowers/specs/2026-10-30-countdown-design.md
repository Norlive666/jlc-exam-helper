# 考试监督：无悬浮窗与一次倒计时

用户已选择一次倒计时：输入 X 分钟，点击“定时开始”后生效。到时在当前应用中开始，不打开测试页或其他页面。

应用显示名改为“考试监督”，保留应用 ID、配置与既有无障碍兼容声明。删除悬浮窗实现及其专属测试；立即重识别、识题历史改由应用内入口提供。通知栏关闭、异常重试、选项点击、DeepSeek 接入、内置测试题保持现有行为。

配置页新增分钟输入和“定时开始”。只接受正整数分钟；Key、通知与无障碍服务就绪后才设置倒计时。设置新倒计时会停止当前识题并替换旧倒计时。倒计时期间不截图、不请求模型、不点击；只显示带取消入口的状态通知。离开配置页继续等待，重新点击桌面图标不会提前启动或重置已有倒计时。

倒计时由已连接的无障碍服务持有，以 elapsedRealtime 计算截止时间，使用主线程 Handler 检查剩余时间，包含休眠经过的时长。手机休眠时不唤醒或解锁；到时处于锁屏/灭屏则复用现有识屏保护，等到可读取时处理。无需新增闹钟权限。强制停止、进程终止或服务断开会取消本次倒计时；重新启用服务本身不会恢复或自动开始任务。

通知关闭、应用内停止、立即开始、服务中断和销毁都取消旧倒计时。到期只启动一次。权限或 Key 不可用时显示失败状态，不在恢复权限后隐式执行旧计划。手动立即重识别仍使用串行执行线程和既有旧结果失效机制。

验证包括：到期前无识题、到期后启动、不跳转页面、后台等待、重复设置替换、通知取消、立即启动取消等待、通知权限关闭时不执行、服务中断取消，以及桌面重开不打断倒计时。最后通过 GitHub 运行全部测试并构建，核对 APK 显示名、版本、无悬浮窗类及保留的无障碍反馈声明。真机运行效果单独标记待验证。
