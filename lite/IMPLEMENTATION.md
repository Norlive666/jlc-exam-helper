# 0.2.0 Operit 模块替换

按用户已批准的要求，修正 0.1.0 未真正复用 Operit 识屏执行模块的问题。

1. 从 OperitAccessbility 原服务删去文字输入、长按、滑动与跨应用 Binder，保留截图、界面 XML 和点击；合并进当前 APK，避免要求用户安装第二个组件。
2. 引入 Operit 原版 ImagePoolManager，替换自写截图压缩；仅保留图片池所需的路径与日志依赖。保留现有单一 DeepSeek 接口、选项协议、通知和设置。
3. 保留 19 个行为回归测试，加入真实位图编码回归测试；在 GitHub 构建并检查 APK 中实际包含原模块。真实手机与真实 API 成功率仍需设备验证。

不改变应用范围，不增加悬浮窗、确认步骤或导航能力。保留应用 ID，版本提升为 0.2.0。来源、基线、删改范围在 UPSTREAM.md 逐项记录。
